## `legvise audit`

### `legvise audit clauses SESSION`

### `legvise audit session SESSION`

| option | default | what it does |
| --- | --- | --- |
| `--stage` |  | Only decisions taken at this stage. |
| `--limit` | `50` | Most rows to print. |

### `legvise audit shape SESSION`

Print how much of a session was cheap screening and how much was pricing.

### `legvise audit stages SESSION`

Count what each stage of a session decided, busiest first.
