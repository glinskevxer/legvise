## A clause fired

Every refusal quotes a clause and the clause is stored on the plan, so
start by counting them across the session rather than reading one.

```
legvise scan refusals --session SESSION
```

| stage | clauses | what it means | where to look |
| --- | --- | --- | --- |
| BOOK | 4 | The feed sent something malformed. Read the levels back and compare them against what the venue is showing. | `legvise book levels VENUE SYMBOL bid` |
| STALE | 2 | Either the feed has stalled or the two venues are being polled too far apart. The confidence slope says which. | `legvise book confidence VENUE SYMBOL` |
| TICK | 4 | The instrument on file disagrees with the venue. Check the tick, the lot and the notional bounds against the venue's own listing. | `legvise instrument show VENUE SYMBOL` |
| DEPTH | 2 | The book cannot fill the size the desk wants, or filling it would sweep past the venue's depth limit. Read the depth at the limit. | `legvise book depth VENUE SYMBOL` |
| FEE | 2 | No fee tier resolved, which usually means the trailing volume was never recorded. Nothing prices until it is. | `legvise fee show VENUE` |
| BAND | 2 | Inventory is at a floor or over a ceiling. The report says what would square each asset and what has to move rather than trade. | `legvise report inventory` |
| CAP | 3 | The desk is at an exposure limit. A trim is the caps working; a stop means the gross cap is binding and nothing else will price. | `legvise inventory exposure` |
| EDGE | 2 | The edge did not clear the floor, which is the normal case. Count the clauses across the session before changing anything. | `legvise scan refusals --session SESSION` |

## Nothing priced at all

A scan that considered no symbols is a desk that is not set up, not
a quiet market. The desk report is the difference.

```
legvise report desk
```

## The numbers look wrong

Read the book back and re-derive it. Nothing here can fail on a file
this tool wrote and nothing else has touched.

```
legvise db verify
```

## The file is growing

```
legvise db prune --keep-days 30
legvise db vacuum
```

The newest snapshot of every market survives whatever its age, and so
does any session with a fill against it.
